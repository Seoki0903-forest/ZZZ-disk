# 앱의 자동 다운로드

앱 업데이트는 Google Play 테스트 트랙에서 설치합니다. 이 저장소의 파일은 앱 실행에 필요한 판정 데이터와 OCR 모델입니다. APK 자동 설치 기능은 제공하지 않습니다.

## 판정 데이터

앱 시작 → GitHub main의 현재 커밋 조회 → 해당 불변 커밋의 data/manifest.json → 변경되거나 없는 캐릭터 JSON 및 recognition.json만 다운로드 → SHA-256/스키마/명칭 검증 → 활성 manifest 원자 교체 순서입니다. 새 설치는61개 캐릭터 파일과 언어 명칭 사전1개를 받습니다. 현재 데이터에는 미완성 캐릭터1명이 별도 표시되며 판정에서 제외됩니다.

네트워크 실패·API 제한·검증 실패에는 마지막 정상 데이터를 유지합니다. 최초 설치에서 판정 데이터를 받지 못했다면 준비될 때까지 판정을 시작하지 않고 다시 확인할 수 있습니다. 파일을 올릴 때는 모든 해시와 manifest를 한 커밋으로 갱신합니다. JSON은 LF 줄바꿈을 유지합니다.

## OCR 모델

기본 인식은 ML Kit이며 러시아어/태국어는 고정 tessdata_fast 커밋의 rus/tha 및 eng 파일을 공식 Tesseract GitHub에서 자동 다운로드합니다. 이 기본 모델 파일도 크기와 SHA-256을 검증합니다.

보조 제목 인식은 ocr-models-v1 Release에서 한국어(약13.5MB), 중일문(약16.6MB), 라틴(약7.9MB), 키릴(약8.1MB), 태국어(약7.9MB) 중 선택 언어의 모델 하나만 자동 다운로드합니다. en/de/fr/es/pt/id/vi는 라틴, ja/zh-cn/zh-tw는 중일문, ko/ru/th는 각각 한국어/키릴/태국어 모델을 사용합니다. 모든5개를 사용자가 받을 필요는 없습니다.

전송 중인 파일은 .part로 저장하며 고정 크기와 SHA-256을 확인하고 정상 파일로 원자 교체합니다. 실패한 임시 파일은 제거합니다. 보조 모델 준비 실패는 기본 인식을 차단하지 않으며 다음 정상 앱 준비 시 다시 시도합니다. 기본 제목 재시도까지 실패한 프레임에만 보조 모델을 실행합니다. 일반 인식 성공 때마다 이중 OCR을 수행하지 않습니다.

HTTPS나 SHA 검증을 끄지 마세요. 기존 모델 Release/태그/파일은 삭제·교체하지 마세요. 새 모델은 새 버전 태그와 앱 내 고정 크기/해시로 배포합니다. 이 저장소에 서명키, 비밀번호, 비공개 앱 소스, 사용자 게임 화면을 업로드하지 않습니다.
